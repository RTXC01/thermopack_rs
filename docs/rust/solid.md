# Melting and sublimation lines

This module implements the melting and sublimation line correlations of the
checked-in ThermoPack fork.

## Source scope

| Original routine | Rust |
| --- | --- |
| `src/solid_saturation.f90:melting_pressure_correlation` | `solid::melting_line` |
| `src/solid_saturation.f90:melting_pressure` | `solid::melting_pressure` |
| `src/solid_saturation.f90:sublimation_pressure_correlation` | `solid::sublimation_line` |
| `src/solid_saturation.f90:sublimation_pressure` | `solid::sublimation_pressure` |
| `src/solid_correlation_datadb.f90` | `solid_data` (generated) |

The parameter database is generated by `tools/rust_port/generate_solid_data.py`
from `src/solid_correlation_datadb.f90`: 23 melting curves and 16 sublimation
curves with their correlation label, triple point temperature, temperature
limits, reducing parameters, coefficients, exponents and reference.

The generated numbers use a round-trip format. The source tables carry up to
thirteen significant digits and two coefficients of the propane melting curve
differ in their last digit, which a fixed format would silently remove.

## Model

Both line families use the same reduced-temperature sum with a different
second term:

* the melting correlation uses $(T_\mathrm{red}-1)^{e}$,
* the sublimation correlation uses $(1-T_\mathrm{red})^{e}$,
* the first terms use $T_\mathrm{red}^{e}$, the third terms
  $\ln(T_\mathrm{red})^{e}$ and the remaining terms
  $(T_\mathrm{red}^{e}-1)$.

The last character of the correlation label selects the final expression:
`1` keeps the sum, `2` exponentiates it and `3` exponentiates the sum
divided by the reduced temperature. The `MP` melting label is a separate
two-branch correlation that the source splits at 22 K.

The temperature grid follows the source: the melting line starts at the triple
point and reaches the larger of the requested temperature and 1.1 times the
triple point temperature, limited by the correlation's maximum temperature. The
sublimation line starts at the smaller of the requested temperature and 0.9
times the triple point temperature, raised to the correlation's minimum
temperature, and reaches the triple point.

## Source limitations reproduced

* **Hydrogen sulfide.** The sublimation record of hydrogen sulfide carries the
  label `S2`, which has no fourth character. The original selects the final
  expression by that character and stops with an error. The native model
  reports the same error.
* **Missing correlations.** A component without a melting or sublimation
  record is not a line. The original returns an empty line, the native model
  reports an error.
* **Undefined values.** The xenon sublimation line at 50 K produces an
  undefined value in the original because the reduced temperature is not
  positive. The native model reproduces the undefined value.
* **Scaling to the equation of state.** The original can rescale the reducing
  pressure so that the triple point matches the bubble pressure of the active
  equation of state. That variant needs the mixture flash machinery and is
  not part of this port.

## Validation

`tools/rust_port/validate_solid_lines.py` compares the native model against
the exact-source library through a reference probe that installs the requested
component in the source globals, calls the source routine and restores the
globals afterwards.

* 156 cases: 23 melting and 16 sublimation components at four temperature
  limits each, with seven points per line.
* 152 cases match, covering the temperature grid and the pressure of every
  point. The tolerance is a relative 1e-10 with an absolute 1e-4 Pa, because
  some melting curves subtract two nearly equal numbers. The krypton line at
  its triple point, for example, cancels two terms of about 2346 Pa to a
  result of 0.72 Pa, which amplifies the rounding of the exponentiation by a
  factor of about three thousand. The thin link time optimization can also
  contract a multiplication and an addition into a fused operation in one
  binary and not in another, so the tolerance covers that rounding
  difference. The recorded validation run matched exactly.
* The 4 remaining cases are the hydrogen sulfide sublimation lines, where the
  original stops with an error and the native model reports the same error.

The committed fixtures are `tests/fixtures/solid_lines.csv` and
`tests/fixtures/solid_lines_status.csv`; the test is `tests/solid.rs`.

## Remaining scope

* The solid Gibbs energy models of carbon dioxide and water, the solid
  saturation pressure, the three-phase envelopes and the hydrate model are
  not yet ported.
* The scaling of the reducing pressure to the equation of state is not
  ported.
